# SPLENDER 方案 v2：重做版

日期：2026-10-04。本文取代 `docs/planning-drafts/2026-10-04/` 里的 Astra 草稿，成为后续开发的唯一依据。Astra 草稿保留作参考资料，其中投射工作流和 Blender 键位调研两部分被本文吸收。

文中数字分三种，分别标注：**实测**（今天在这台电脑上跑出来的）、**旧版记录**（Codex 压力测试留下的数据）、**估计**（我的判断，未经验证）。

---

## 1. 一句话定位

SPLENDER 是一个独立的贴图创作程序，把三样东西做进同一个窗口：

| 取自 | 拿什么 | 不拿什么 |
|---|---|---|
| Substance Painter | 多通道图层绘制、蒙版、填充层、智能材质、网格贴图烘焙、导出预设 | 它的 4K 工作分辨率上限 |
| Substance Designer | 节点式程序材质、生成器、滤镜，节点图可以直接当图层用 | 独立成另一个软件的割裂感 |
| Blender | 模块化窗口、视口操作与键位、着色模式与 HDRI、雕刻 | 多边形建模、动画、渲染器、物理模拟 |

核心卖点只有一条：**在 8GB 显存的显卡上，16K 多通道多图层绘制依然跟手。**

多边形建模、动画不在范围内，模型靠导入。如果以后要加建模，另立阶段。

## 2. 现在为什么差得远

旧版是一天之内叠出来的三代实验：同步球体、异步球体、OBJ 网格，后一代继承前一代的窗口类。它证明了 16K 数据通路能走通，但从没被设计成一个程序。具体问题如下。

### 2.1 界面没有框架

- 整个界面写在一个构造函数里（`dcc_ui/studio.py`，一个 `__init__` 排完所有控件），布局是写死的。
- 没有「区域」「编辑器」「面板」的概念，所以不能拆分窗口、不能换编辑器类型、不能保存工作区。
- 控件靠往窗口对象上挂属性互相找，甚至用隐藏的下拉框当数据模型。加一个功能就要改这一个大函数。
- 没有统一的操作、键位、属性系统。菜单、按钮、快捷键各写各的。
- 启动靠 `launch.cmd`，带黑窗，没有图标、没有工程文件关联。

### 2.2 绘画卡的真实原因

显卡算力完全够用，卡在结构上。

| 问题 | 证据 |
|---|---|
| 显存里每种格式只放 512 页，相当于一张 16K 贴图的八分之一 | 旧版代码 `--pages 512` |
| 内存缓存只有 64MB，这台机器有 32GB | 旧版代码 `cpu_bytes=64*1024**2` |
| 缓存一满，绘制要等「显存读回、压缩、写盘」整条链，等不到就下一帧重试 | 旧版记录：180 笔压力测试发生 1745 次淘汰，首帧延迟 p95 230ms，最大 340ms |
| 一笔最多碰 51 个分块（三通道联动），超了整笔取消。51 块只占 16K 贴图面积的 1.2% | 旧版代码 `GestureLimitExceeded` |
| 每个笔触、每个分块、每个通道各发一次显卡指令，全部由 Python 逐个循环 | 旧版代码 `paint_group` |
| 每个纹素都遍历一次整个模型的 BVH 做遮挡判断 | 旧版着色器 `hidden()` |
| 三张完整 16K 合成贴图常驻显存，占 2GB，且没有多级渐远，缩小看会闪 | 旧版代码 |
| 笔刷最大 1024 像素，在 16K 贴图上只有 6% 宽 | 旧版界面 |

### 2.3 功能面

视口只有正交相机，不能平移，没有透视。光照是一个固定方向光。只认 OBJ，单模型单纹理集。通道只有颜色、高度、粗糙度。图层上限 8 层，混合模式 3 种。程序图案是 3 个 512 像素预设。没有节点。没有雕刻。导出只有颜色 PNG。

### 2.4 Astra 草稿的问题

- 它把界面定为「保留一个视口、固定布局」，没有处理模块化窗口。
- 它的第一阶段是「先建立延迟测量闭环」，没有给出让绘画变流畅的设计。
- Designer 式节点被排在最后一个阶段，只算「部分能力」。
- 通篇是验收条款，缺产品架构。

## 3. 外部对照

今天联网核对的结果，来源附后。

| 产品 | 事实 | 可信度 |
|---|---|---|
| ArmorPaint 1.0 | 2026-09-04 发布，开源（zlib 许可），全部用 C 重写，带图层、节点、基础雕刻和 UV 编辑，宣称高端显卡可 16K 绘制 | 新闻报道 |
| ArmorPaint 1.0 | 每个图层是三张整幅贴图，8 位下 16K 一层占 3GB 显存。撤销步数默认 4 步，每步再复制整层 | **我今天读了它的源码**（`slot_layer.c`、`history.c`） |
| Blender 5.3 | 目标 11 月 17 日发布，加入原生贴图图层系统并重写烘焙。目前是测试版，细节未定 | 新闻报道 |
| Substance Painter | 工作分辨率上限 4K，导出上限 8K | 搜索摘要，官方页面打不开，未直接核实 |

结论：

1. **不拿 ArmorPaint 当底座。** 它的存储方式决定了 8GB 显卡上 16K 只能有一两层。要改就得重写它的核心，等于在别人的 C 代码里重做。它的许可很宽松，算法和做法可以借鉴。
2. **不做 Blender 分支。** Blender 自己马上要出图层系统，但它的绘制仍以 CPU 为主，16K 流畅不是它的目标。做分支还要背 GPL 许可和两百万行代码的合并负担。
3. **SPLENDER 的位置：** 16K 在主流显卡上流畅，加上节点和图层合一。这两点目前没有产品同时做到。

## 4. 路线决定

**自己重做，独立程序。** 理由见上。

技术栈保持 Python 3.11、PySide6（Qt）、OpenGL 4.5，不换语言。理由：

- 像素运算全在显卡上，Python 只负责每帧打包一次任务。实测打包耗时不到 1 毫秒。
- 这个产品要补的功能非常多。Python 改完立刻能跑，功能推进最快。
- Qt 对数位板压感和中文输入法的支持最成熟。Painter 和 Designer 本身也是 Qt 程序。
- 整个程序是 Python，用户和 AI 写插件没有门槛。
- 引擎与界面隔着一层接口。以后如果实测发现 Python 成了瓶颈，只换引擎内部，界面不动。

旧代码的去留：

| 处理 | 内容 |
|---|---|
| 归档到 `legacy/` | 全部旧原型、检查点文档、证据目录 |
| 借用思路 | 流式 PNG 导出、原子保存、测试用 OBJ、数值拖动框和色轮控件 |
| 丢弃 | 三代叠加的窗口类、过紧的版本账本、逐页逐通道循环、每纹素 BVH 遮挡 |

## 5. 本机实测依据

今天在 RTX 3070 Ti 上用隐藏的显卡上下文实测，没有开窗口。测试脚本和原始结果存在 `docs/evidence/2026-10-04-feasibility/`。

### 5.1 批量盖章

做法：一帧内所有笔触、所有受影响的页面，合成一次显卡提交。

| 笔刷直径（16K 纹素） | 每帧笔触数 | 涉及页面数 | 显卡耗时 |
|---|---:|---:|---:|
| 256 | 8 | 8 | 0.07 ms |
| 1024 | 8 | 63 | 0.16 ms |
| 2048 | 6 | 184 | 0.34 ms |
| 4096 | 4 | 569 | 0.79 ms |
| 8192 | 4 | 1881 | 2.8 ms |

直径 8192 是整张 16K 贴图的一半宽。全精度下也只占一帧时间的六分之一。

### 5.2 换页与合成

| 项目 | 结果 |
|---|---|
| 显存读回到内存 | 1.74 GiB/秒 |
| 内存上传到显存 | 1.26 GiB/秒 |
| LZ4 压缩（单线程） | 650 MiB/秒，解压 1240 MiB/秒 |
| 合成 1024 页，2 层 | 1.3 ms |
| 合成 1024 页，8 层 | 4.0 ms |
| 合成 1024 页，16 层 | 7.7 ms |

### 5.3 硬件稀疏贴图

| 项目 | 结果 |
|---|---|
| 创建一张带完整多级渐远的 16K 虚拟贴图 | 占用显存 0 |
| 提交一个 256×256 页 | 26 微秒 |
| 提交 512 页 | 13 ms |
| 已提交区域采样 | 正确 |
| 最大稀疏贴图尺寸 | 32768 |

这三组数字是整个引擎设计的地基。结论：显卡远没到极限，只要结构对，16K 流畅是能做到的。

## 6. 界面框架

这是「模块化窗口」的答案。目标是和 Blender 同一套思路：**窗口由区域拼成，每个区域可以是任何编辑器。**

### 6.1 区域

- 主窗口的工作区是一棵拆分树。每个叶子是一个区域，每个区域装一个编辑器。
- 区域标题栏最左边是编辑器类型按钮，点开可以换成任何编辑器。
- 拆分：从区域角落往里拖，或在标题栏右键选「垂直拆分」「水平拆分」。
- 合并：从角落往相邻区域拖，被拖入的区域消失。
- 交换：按住 Ctrl 拖角落到另一个区域。
- 最大化：鼠标停在区域上按 Ctrl+空格，再按一次还原。
- 弹出：把区域复制成独立窗口，放到副屏。
- 区域之间的分隔条可以拖。

### 6.2 工作区

- 顶栏有工作区标签：绘制、材质、UV，以后加雕刻、烘焙。
- 每个工作区记住自己的区域布局和每个编辑器的状态。
- 可以新建、复制、改名、删除、排序。布局存进用户配置，也可以随工程保存。

### 6.3 编辑器

| 编辑器 | 作用 | 首版 |
|---|---|:-:|
| 3D 视口 | 看模型、绘制、导航 | 有 |
| UV / 图像 | 平面查看贴图和 UV，平面绘制 | 有 |
| 图层 | 图层栈、蒙版、混合、通道 | 有 |
| 属性 | 笔刷、工具、纹理集、显示设置 | 有 |
| 资源库 | 笔刷、笔尖、材质、HDRI | 有 |
| 信息 | 操作记录、性能面板 | 有 |
| 偏好设置 | 缓存预算、键位、主题、行为 | 有 |
| 节点 | 程序材质图 | M3 |
| 大纲 | 模型部件、纹理集 | M2 |
| 历史 | 撤销列表 | M2 |

每个编辑器内部分四块，和 Blender 一致：标题栏、工具栏（按 T 开关）、侧栏（按 N 开关）、主区域。

### 6.4 让「加功能」不再改界面代码

框架提供五样东西，所有功能都通过它们接入：

1. **属性**：每个可调的值声明一次，带类型、范围、默认值、单位、说明。界面控件自动生成，自动存盘，自动出现在偏好或面板里。这条直接落实「所有东西都要可调」。
2. **操作**：每个动作是一个操作，有名字、可用条件、是否可撤销。菜单、按钮、快捷键、搜索调用的是同一个操作。
3. **键位表**：按上下文分层（窗口、编辑器、模式、工具）。默认预设对齐 Blender 4.3.2，另备 Painter 风格预设。偏好设置里可以逐条改，冲突会提示。
4. **面板**：声明属于哪个编辑器、哪个标签页、什么条件下出现，用布局语句排内容。面板可以折叠。
5. **上下文**：操作和面板拿到的是「鼠标所在区域」的上下文，所以快捷键永远作用在鼠标底下的那个编辑器，和 Blender 一样。

另有：操作搜索（F3）、统一撤销历史、通知机制（数据一变，相关编辑器自动刷新）、后台任务进度显示。

插件用的就是这同一套接口。

### 6.5 观感

- 深色中性灰，一个强调色，细边界。不要卡片、渐变、阴影。
- 统一的线性图标。纯图标按钮都带中文提示。
- 主题由一张色板和尺寸表生成，界面缩放比例可调。
- 界面文字只说这东西是什么、能做什么。

## 7. 绘制引擎

这是「绘画不卡」的答案。

### 7.1 三条铁律

1. **笔划路径上不碰磁盘。** 磁盘读写只在后台线程。
2. **笔划永远不因为太大被取消。**
3. **每帧发给显卡的指令数是常数。** 不随笔刷大小、页面数、图层数增长。

### 7.2 分页存储

- 贴图切成 256×256 的页。只有画过的页才占空间。
- 每个图层的每个通道组是一座稀疏的金字塔：从 16K 的 64×64 页，逐级减半到 1 页。画完全精度后，上级自动更新。
- 通道打包成四种页：

| 页 | 格式 | 内容 |
|---|---|---|
| 颜色页 | RGBA8 | 基础色 RGB，覆盖度 |
| 金属粗糙页 | RGBA8 | 金属度及其覆盖度，粗糙度及其覆盖度 |
| 高度页 | RG16F | 高度，覆盖度 |
| 蒙版页 | R8 | 图层蒙版 |

  AO、法线、自发光、不透明度通道在 M2 按同样方式加入。每个通道有独立覆盖度，所以可以只画粗糙度不动颜色。

### 7.3 三级缓存

| 级 | 位置 | 默认预算（8GB 显卡，32GB 内存） | 进出方式 |
|---|---|---|---|
| 一级 | 显存页池 | 3 GiB，约 1.2 万页 | 直接读写 |
| 二级 | 内存，冷页用 LZ4 压缩 | 12 GiB | 后台批量读回与上传，实测每秒 1 GiB 以上 |
| 三级 | 工程文件本身和暂存文件 | 磁盘剩余空间 | 后台线程 |

- 预算全部可在偏好设置里改，默认值按检测到的显存和内存自动给。
- 显存页池始终保留一段空闲页。低于水位时后台把最久没用的页读回内存，每帧限时。
- 一张画满的 16K 通道连同金字塔是 1.33 GiB。显存能同时放两张多，内存再放九张以上。实际工程是稀疏的，远到不了这个量。

### 7.4 一帧里发生什么

1. 输入事件只入队，带时间戳。
2. 把新采样沿路径按间距生成笔触。笔触的落点、法线从视口的几何缓冲里取，不做 CPU 射线求交。
3. 算出受影响的页，给没有的页分配槽位，首次触碰的页先复制一份留作撤销。
4. **一次提交**把这一帧所有笔触盖到所有页上。做法是把模型三角形按 UV 光栅化到页里，每个纹素直接拿到自己的三维位置和法线，再按与笔触中心的距离算覆盖。
5. 一次提交更新上级金字塔。
6. 一次提交把脏页合成进显示贴图。
7. 渲染视口。

第 3 步到第 6 步的显卡总耗时，实测量级是 1 到 5 毫秒。

### 7.5 笔刷与遮挡

- 笔刷大小有两种单位：视口像素（看到多大就画多大），场景单位（在表面上恒定）。
- 笔触是贴在表面上的圆盘，沿法线方向有限厚度，背面和厚度以外的表面不受影响。不需要遍历 BVH。
- 投射类工具才用相机深度图做遮挡。
- 笔刷上限 8192 纹素。

### 7.6 撤销

- 每笔记录它首次触碰的页的旧版本。撤销是把页表指回旧页，不复制像素。
- 撤销预算按字节算，默认 2 GiB，可调。旧步骤先压缩进内存，再进磁盘，最后才丢弃。
- 上级金字塔不存历史，撤销后从全精度页重算。

### 7.7 显示

- 合成结果放在硬件稀疏贴图里。16K 的虚拟尺寸不占显存，只提交屏幕上看得见的页、看得见的层级。
- 每帧用一张低分辨率反馈图找出屏幕需要哪些页。需要的页还没好时，先显示上一级的模糊版本，好了再换，不卡界面。
- 粗层级常驻，所以转动模型永远有图可看。
- 采样是显卡原生的三线性加各向异性，斜面上也清晰。
- 这台机器的驱动实测支持全部所需扩展。不支持稀疏贴图的显卡退回整幅贴图，分辨率按显存封顶。

### 7.8 图层合成

- 每个页独立合成：从下到上按混合模式、不透明度、蒙版逐层叠。
- 填充层是一组常数或一张节点图的输出，不占页。
- 只合成屏幕上看得见的页。看不见的脏页只打标记。

### 7.9 兜底

巨型笔刷快速扫过大片没画过的区域时，新页需求可能超过换出速度。这时先把这一段笔触盖到低一级的金字塔上，屏幕立刻有反馈，全精度在后台按笔触记录补齐。导出前等补齐完成。这是安全阀，首版先实现水位换出，安全阀在 M1 后半段加入。

### 7.10 工程文件

- 单个 `.splender` 文件，内部是页数据库。打开工程不需要把贴图全读进来，看到哪读到哪。
- 保存只写改过的页，一次事务完成，中途断电不会坏文件。
- 自动保存和崩溃恢复在 M5。

## 8. 视口

- 相机：透视与正交切换，轨道旋转、平移、缩放，标准视图，查看全部，查看选中。
- 键位默认对齐 Blender 4.3.2：中键旋转，Shift+中键平移，Ctrl+中键或滚轮缩放，小键盘 1/3/7 视图，小键盘 5 切换透视，Home 查看全部，F 调笔刷大小，Shift+F 调强度，`[` `]` 步进，Ctrl+Z 撤销，Ctrl+Shift+Z 重做，T 工具栏，N 侧栏。
- 着色模式三种：
  - **实体**：工作室光或 Matcap，可以单独看某个通道。
  - **材质预览**：PBR 加 HDRI 环境光。可调 HDRI、旋转、强度、背景可见度、背景模糊。
  - **通道隔离**：只看基础色、粗糙度、金属度、高度之一。
- 自带 8 张 HDRI 和一组 Matcap，来自 Blender 发行包，许可是 CC0。可以加载自己的 `.hdr` 和 `.exr`。
- 高度通道在视口里实时转成凹凸。真实位移在 M4。
- 色彩管理：首版提供标准、Filmic、AgX 三种显示变换和曝光。接入 OCIO 配置在 M2。

## 9. Painter 部分

### 9.1 M1 内容

## 10. Designer 部分（M3）

- **节点编辑器**是一种编辑器，可以放进任何区域。
- **图的三种用途**：材质图当填充层，蒙版图当生成器，滤镜图作用在图层内容上。
- **参数外露**：图里标记为外露的参数，在图层属性里显示成滑杆。平时调滑杆，需要时才打开节点图。
- **求值方式**：按页、按层级按需求值，和绘制引擎用同一套页池。改一个参数只重算依赖它的页。先出低精度预览，再补全精度。所以 16K 的程序材质也不是把 512 图放大。
- **首批节点**：

| 类 | 节点 |
|---|---|
| 生成 | 纯色、渐变、形状、砖块、平铺生成器、Perlin、Simplex、Worley、细胞、分形叠加 |
| 调整 | 混合、色阶、曲线、色相饱和度、渐变映射、反相、直方图扫描 |
| 滤镜 | 高斯模糊、方向模糊、坡度模糊、锐化、边缘检测、距离 |
| 变形 | 2D 变换、方向扭曲、矢量扭曲、平铺 |
| 转换 | 高度转法线、法线转曲率、高度转 AO、高度混合 |
| 输入 | 网格贴图、图片、外露参数、位置（用于三向投射） |
| 自定义 | 表达式节点，直接写一小段着色器 |

- 图可以存成资源，成为「智能材质」。

## 18. 第二阶段：雕刻、渲染器、插件化（2026-10-05 起）

### 18.1 新增方向

你在 10-05 定的方向：做成 ZBrush、Substance Painter、Substance Designer、Blender 四合一的高性能版本；内置渲染器，像 Blender 里 EEVEE 和 Cycles 的关系；外部渲染器（如 Arnold）可以注册进来；整个程序像 Blender 一样模块化。

### 18.2 对照的事实

| 对象 | 事实 | 来源 |
|---|---|---|
| ZBrush | 当前 2026.2（2026-04）。2026.0 加了 Python 脚本；2026.2 能把雕刻直接发给 Substance 3D Painter | cgchannel 2025-09、2026-04 报道，Maxon 发行说明 |
| Arnold | 本机装着 Maya 2026 用的 Arnold 7.4.0.0（含 Python 接口、GPU 渲染、OptiX 8）。实测能在 SPLENDER 的进程里直接调用 | 本机实测 |
| Arnold 授权 | 本机没有授权，成图带水印；授权检查要等约 14 秒 | 本机实测；Autodesk 帮助文档 |

### 18.3 插件化

和 Blender 一样，功能由注册的模块组成：编辑器、面板、操作、工具、菜单、键位已经是注册制，新增两类：

- **渲染引擎**：`RenderEngine` 基类，声明名字、能不能在视口里实时预览、能不能出最终图，以及自己的渲染设置。渲染设置跟着工程保存。
- **插件**：一个 Python 包或文件，写明名字、作者、版本、分类，提供 `register()` 和 `unregister()`。内置插件放 `splender/addons/`，用户插件放用户目录的 `addons/`。偏好设置里有插件页，可以启用、停用、安装。Arnold 就是第一个插件。

### 18.4 渲染

| 引擎 | 相当于 | 用途 |
|---|---|---|
| 工作台 | Workbench | 实体、Matcap，看形 |
| 实时 | EEVEE | 现在视口的 PBR 加环境光，出图时超采样，秒出 |
| 路径追踪 | Cycles | 显卡计算着色器路径追踪，物理正确，视口里渐进预览，F12 出最终图 |
| Arnold（插件） | 外部引擎 | 调用本机安装的 Arnold，材质自动转成 standard_surface |

渲染时图层先合成成普通贴图（默认 4K，可调），引擎只读场景快照（`splender/render/scene.py`），不碰图层引擎，所以能放在后台跑。F12 出图到「渲染结果」窗口，可存 PNG 和 EXR。

### 18.5 雕刻（ZBrush 部分）

- **数据全在显卡上**：顶点位置、法线、遮罩存在显存里，每 256 个顶点一块。笔刷是计算着色器，显卡自己挑出被笔刷碰到的块，CPU 只上传这一帧的笔触。
- **笔刷**：标准、黏土、黏土条、平滑、抓取、膨胀、捏合、压平、折痕、遮罩。XYZ 对称，压感控制大小和力度。
- **撤销**：和贴图一样按块写时复制，只存被改过的块。
- **拓扑**：细分（Loop）、体素重构（类似 DynaMesh）。之后做动态拓扑、雕刻图层、自动重拓扑。
- **和绘制打通**：雕刻和绘制用同一份顶点，雕完直接在上面画；高模细节烘焙成低模的法线、AO、曲率贴图，进 Painter 的图层。
- **性能目标**：RTX 3070 Ti 上 2000 万三角形可以流畅雕刻和转视角。

- 实测：310 万三角形每帧 32 个笔触，中位 2.8 毫秒，最长 8.1 毫秒；抬笔读回 933 块 30 毫秒；细分 9024 → 36096 三角形 0.11 秒。
- **体素重构**（类似 DynaMesh，Ctrl+R）：稀疏分块距离场，射线绕数判断内外（重叠合并、翻面、空心都对），开口自动封上，非流形边拆开，小碎块去掉，切向放松。实测 78 万三角形重构成 139 万三角形 1.0 秒，重构到 988 万三角形 4 秒；九种测试模型全部输出封闭、无破边的网格。遮罩和材质跟着搬过去。
- **自动展开 UV**：重构后的模型没有 UV，回到绘制模式时自动展开（偏好设置里可关）。按角度分块、平面投影、凸包转最小包围矩形、天际线排布。实测 139 万三角形 1.3 秒，247 万三角形 2.3 秒，贴图利用率 55% 左右，无翻面，拉伸 p5–p95 在 0.81–1.05。属性编辑器新增「模型」页，可以手动展开、调角度限制和块间距。xatlas 试过：35 万三角形要 106 秒，而且卡住界面，所以没用。

**参考的开源项目**：路径追踪的 GGX 采样参考 GLSL-PathTracer（MIT），雕刻笔刷公式和体素重构思路参考 SculptGL（MIT），图标来自 Lucide（ISC）。

**还没做**：降噪；烘焙（法线、AO、曲率）和旧 UV 贴图搬到新 UV；动态拓扑；雕刻图层；Designer 节点；智能材质；UV 视图里画。

**M4 第一部分：模型贴图烘焙、生成器蒙版、智能材质（2026-10-06）**

- 模型贴图（Substance Painter 的 Mesh Maps）：每套纹理集一组，遮蔽、曲率、厚度、世界法线、位置。属性编辑器「纹理集」页的「模型贴图」面板烘焙，带五张缩略图，设置都可调（分辨率、遮蔽采样和距离、厚度距离、曲率平滑和对比、扩边、只算自身遮挡）。跟着工程保存。
- 烘焙在显卡上做：UV 空间光栅化，遮蔽和厚度用路径追踪的 BVH 发射线（每个纹素随机旋转的 Hammersley 采样），跳跃泛洪扩边，生成 mip。按帧限时推进，界面不卡，状态栏有进度。实测 100 万三角形、2048²、64 采样 7.1 秒；14 万三角形 5 秒。
- 生成器蒙版：图层可以挂生成器（边缘、凹陷、遮蔽、朝向、薄处、渐变、斑驳），带范围、过渡、斑驳、斑驳大小、随机种子、方向、反转；斑驳是按世界位置算的三维噪声，接缝两边连续，缩小时自动去掉过细的倍频不闪。和画的蒙版相乘。合成器里每个纹素只取一次模型贴图。
- 智能材质 11 种：青铜古器、锈铁、掉漆机甲、黑漆描金、青瓷、苔石、初雪、鎏金、旧皮革、焦木、古玉。资源库「智能材质」页点一下，或图层「新建 → 智能材质」。整组一步撤销。没有模型贴图时自动开始烘焙。
- 视口叠加烘焙出的遮蔽（可关、强度可调）；导出多了「环境遮蔽」通道。
- 雕刻、重构后回到绘制模式，已经烘焙过的模型贴图自动重烘（可关）。
- 验证：圆环内圈遮蔽 0.83、外圈 1.00；大小球厚度 0.13 对 0.67；立方体边缘生成器棱上 100% 命中、面中间 0%；朝上生成器顶部全覆盖、底部 0；存取逐字节一致。跑分和加生成器之前一致（持续绘制每帧 p50 6.17、p95 9.34 毫秒）。

**M4 第二部分：重构后搬贴图、图层文件夹和调整层、降噪（2026-10-06）**

- 旧 UV 上画的内容搬到新 UV：重构或重新展开 UV 后，每个图层（颜色、金属粗糙、高度、蒙版）按位置从旧模型取过来。新 UV 光栅化出每个纹素的位置和法线，沿法线两个方向对旧模型求交，命中处按旧 UV 双线性取样；UV 没变的部分直接对应。显卡上做，16K 一层 0.36 秒，整个重构流程 0.85 秒，一步撤销。
- 图层文件夹最多套 4 层，可以整组隐藏、调不透明度、挂蒙版和生成器；Ctrl+G 编组，拖进拖出。调整层 5 种：色相饱和度、亮度对比度、色阶、反相、阈值，作用在它下面已经叠好的结果上。没有文件夹时合成走寄存器快路径，跑分和以前一样。
- 降噪：路径追踪出图和视口渲染用 Intel Open Image Denoise 2.5，带反照率、法线辅助通道，显卡或处理器都能跑；视口在若干个采样数节点异步降噪。
- 智能材质缩略图改成路径追踪真实渲染的材质球。

**M4 第三部分：高模法线、导出法线、智能遮罩、部件、UV 视图里画（2026-10-06）**

- 高模烘到低模：「模型贴图」面板指定高模文件，从低模表面沿法线找高模（向外、向里的距离可调，每个纹素 1 到 16 个采样抗锯齿），烘出切线空间法线贴图；遮蔽、曲率、厚度也按高模的细节算。视口、路径追踪、Arnold 都用上这张法线贴图。验证：起伏的高模烘到光滑低模，加法线贴图后的明暗变化和直接渲染高模的相关：视口 0.98、路径追踪 0.985、Arnold 0.967，幅度比 1.00、1.00、0.93。
- 导出法线：烘焙的法线加上手绘高度换算的凹凸合成一张，OpenGL 或 DirectX、8 或 16 位、强度可调。强度 1 时和视口里的凹凸一致：把导出的法线当法线贴图、关掉高度凹凸，视口明暗相关 0.94，幅度比 1.06。导出设置按纹理集：勾哪些通道、尺寸、文件名规则。
- 智能遮罩 14 种（边缘磨损、棱角崩口、手摸包浆、缝里积灰、深处油泥、顶面落尘、一夜积雪、背阴苔痕、溅泥、日晒褪色、薄处透光、水渍、细碎斑点、地衣斑块），图层右键菜单或生成器面板一键套用，一步撤销。
- 部件（ID 贴图）：烘焙时按网格部件、UV 岛或高模部件给每个纹素编号。「部件」生成器在视口里点选部件，只盖住选中的，可以反转；最多 16384 个部件。
- UV 视图里画：UV 编辑器里直接画，笔触按 UV 量距离，和三维视口共用笔划、合并、撤销，有笔刷圈。4096² 上笔迹的位置和粗细与屏幕换算差 1 到 3 个纹素。

**M5 Designer 节点：完成第一版（2026-10-06）**

- 21 种节点。生成：噪波、细胞、砖块、形状、波纹、渐变、划痕、数值、颜色；调整：混合（9 种方式）、色阶、反相、阈值、渐变映射、色相饱和度、转灰度；滤镜：模糊、扭曲、方向扭曲、变换、描边；材质输出：基础色、金属度、粗糙度、高度。生成器都能无缝平铺。
- 显卡求值：每个节点一个片元着色器，参数自动成为 uniform；结果按签名缓存，改一个参数只重算它和下游。1K 默认图第一次 115 毫秒（含编译），改参数后 1.6 毫秒。
- 节点编辑器（「节点」工作区）：拖线连接、拔线改接、框选、右键或 Shift+A 加节点、X 删除、Ctrl+D 复制、每个节点有缩略图，侧栏是参数和大预览，所有改动都能撤销。
- 填充层可以用节点图当内容，平铺次数、偏移、高度强度可调，一套贴图同时最多用 6 张节点图；合成时按显示级别选多级。导出的贴图和节点图输出平均差 0.001。节点图跟着工程保存。

**还没做**：动态拓扑、雕刻图层、自动重拓扑、多分辨率细节（M6）；UDIM、安装包（M7）。
