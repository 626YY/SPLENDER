# 更新记录

每次打包（`tools/make_package.py`）时，最上面这一段会写进包里的「使用说明.txt」，当作「本次更新」。

## 0.3.0（2026-10-09）

补齐从做到交付这一圈：自动保存和恢复、导出模型、同一个工程里雕高模烘低模、16K 模型贴图、改键位、数位板、启动更快。

- 自动保存：默认每 2 分钟把没保存的改动另存一份（停手一秒后才存，正在画的那一笔不打断）。
  存的时候照常画画：16K、两万多页的工程整份存一次约 15 秒，期间每帧只慢约 0.5 毫秒；之后每次只补写变了的，画一笔后约 0.1 秒。
- 程序意外退出（崩溃、被结束、断电）后再打开，会问要不要恢复；恢复出来的是一个新的工程文件，原来的工程文件不动。
  也可以从「文件 → 恢复自动保存…」里找。16K 工程从重新打开到恢复好约 5 秒。
- 偏好设置的「文件」里能改：开关、间隔、等停手多久、最多推迟多久、每帧最多花多少时间、压缩线程数、放哪、最多留几份、恢复到哪。
- 程序内部出错时弹一个说明窗口（同一个错只弹一次），能「复制诊断信息」；「帮助」菜单里也能复制诊断信息
  （版本、系统、显卡、工程概况、最近的日志），反馈问题时一起发过来。崩溃时的调用栈存进日志文件夹。
- Qt 自带的窗口（消息框按钮、文件对话框）改成中文。
- 导出模型（文件 → 导出模型…）：glTF 二进制（.glb）把基础色、法线和遮蔽粗糙度金属度打包贴图装在一个文件里；
  OBJ 保留四边形、按材质分组，旁边写 PNG 和材质文件（.mtl）。能选全部可见的或选中的模型、贴图尺寸、缩放。
  导出面板里勾「连模型一起导出」，导出贴图时把模型也导出到同一个文件夹。重构、自动展开 UV 后导出的 glb 拿进 Blender，
  贴图逐像素对得上；100 万个三角形导出 glb 约 1.4 秒、obj 约 3 秒。
- 导入到当前场景（文件 → 导入到当前场景…）：模型文件里的模型加进现在的工程（每个材质一套新贴图），能撤销；不再只能新建工程。
- 烘焙面板加了「高模（场景里的）」：直接选场景里的模型当高模——比如把模型复制一份、雕刻复制出来的那个、藏起来，
  低模就能烘出它的法线、遮蔽、曲率，不用先导出成文件；和导出成文件再烘的结果一样。雕刻高模之后，用它的贴图会按设置自动重烘。
- 模型贴图（遮蔽、曲率、厚度、法线贴图）能烘到 8K、16K，生成器蒙版的边缘跟着变细。世界位置、世界朝向、部件这三张变化平缓的
  另有「最大」（默认 4K），16K 时显存从约 8 GB 降到约 3 GB；面板上显示大约占多少显存、现在空闲多少。
  16K 带高模约一分半钟烘完，烘的时候视口照常能转（最长一帧从 0.8 秒降到 0.14 秒）；烘好后缩略图、选部件、自动保存都不会卡一下。
- 键位能改了（偏好设置 → 键位）：搜索操作或快捷键，点快捷键那一格再按新的键（键盘、鼠标键、滚轮都行）就改好了；
  勾掉前面的框是停用；改过的旁边有「恢复」，也能全部恢复出厂；同一个键会互相挡住时用橙色标出来、说明在哪会先触发哪个。
  改动立即生效、自动保存，重新打开程序还在。
- 数位板驱动里关了 Windows Ink 也有压感了：偏好设置 → 绘制 →「数位板接口」默认「自动」，有 Windows Ink 的笔事件就用它，
  没有时从驱动带的 WinTab 取压感、倾斜、橡皮端；也能固定成「WinTab」或「Windows Ink」，改了立即生效。
- 启动更快：编译好的计算函数存进用户设置目录（以前存在程序旁边，放在不能写的地方时每次启动都要重新编译），
  第二次起约 3 秒就能画；第一次启动约 10 秒，启动画面上会说明。
- 修了一个问题：16K 贴图上连着对两层铺满的图层做滤镜（比如整层填色后加杂色），会提示「显存页池已满」做不下去。

## 0.2.0（2026-10-08）

照 Photoshop 加了选区。

- 选区工具：矩形选框、椭圆选框（M）、套索、多边形套索（L）、快速选择、魔棒（W）。三维视口里框出来的形状会投到模型上，
  只选看得见的那面；UV 视图里按贴图选。
- 拖之前按住 Shift 是添加、Alt 是减去、Shift+Alt 是交叉；拖的时候按 Shift 是正方形（正圆）、Alt 从中心拉；点一下取消选择。
- 有选区时，画笔、橡皮、减淡加深这些效果笔刷、滤镜、渐变、油漆桶、文字、形状都只改选区里面，羽化过的边是渐变过去的。
- 「选择」菜单：全选、取消选择、重新选择、反选，修改里有边界、平滑、扩展、收缩、羽化；还能把蒙版载入成选区、按选区加蒙版。
- 有选区时：Ctrl+J 只复制选区里的内容，Ctrl+Shift+J 剪切到新图层，Delete 清除选区里的内容；
  新建填充层（Alt+Backspace）、调整层会自动带上和选区一样的蒙版。
- 选区边上有黑白相间、会流动的虚线；在偏好设置的「视口」里能关掉或者调速度、粗细。
- 修了一个老问题：图层蒙版默认是白的时候，模型拉远看，没画过的地方会被错误地挡掉一块。
- 16K 贴图上：框选约 0.15 秒，反选、修改选区 0.1 到 0.35 秒，魔棒约 0.6 秒；有选区时画画每帧不比没选区时慢。

## 0.1.0（2026-10-08）

第一次打成解压就能用的一份：自带 Python 和用到的库，别的电脑不用装任何东西。

- Photoshop 的十六种调整层：亮度对比度、色阶、曲线、曝光度、自然饱和度、色相饱和度、色彩平衡、黑白、照片滤镜、通道混合器、
  颜色查找、反相、色调分离、阈值、渐变映射、可选颜色。色阶、曲线带直方图，都有预设，能自动色调。
- 滤镜菜单：高斯模糊、动感模糊、径向模糊、表面模糊、USM 锐化、高反差保留、添加杂色、中间值、最小值、最大值、浮雕、马赛克、云彩等。
- 绘制工具：渐变、油漆桶、减淡、加深、海绵、模糊、锐化、涂抹、仿制图章、修复画笔、文字、形状。
- 在模型上写字、画形状：字号和描边按屏幕像素，字正对屏幕投到模型上，只写在看得见的那面。
- 第一次在模型上拉渐变、写字时会先自动准备模型贴图，好了直接做完，不用再拉一次。
- 16K 贴图上的油漆桶从一两秒降到 0.75 秒左右；效果笔刷每帧十毫秒上下，画起来是顺的。
- 之前就有的：物体模式、编辑模式（Tab）、雕刻、16K 绘制、图层和文件夹、智能材质、烘焙、材质节点、节点纹理、
  渲染（含 Arnold 插件）、导出，详见 README.md。
